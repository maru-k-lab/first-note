# Icon Placeholders

`icon-192.png` and `icon-512.png` are 1×1 pixel placeholder files.

Before sharing or releasing the app, replace them with proper PNG icons:
- `icon-192.png`: 192×192 pixels
- `icon-512.png`: 512×512 pixels

These are referenced in `manifest.json` and used by iOS Safari's "Add to Home Screen" feature.
